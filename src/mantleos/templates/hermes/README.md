# MantleOS 2 assimilation delta: Hermes

This directory is the public, reproducible delta for the recorded Hermes NEST.
Hermes remains Layer 0, the Default Body, and must retain its ordinary behavior
when Mantle or the AppAI MIND is absent.

Construction is complete enough for review, but the organism is **not born**.
Private state belongs in `/.mantle/`; `COMMUNICATION.TXT` and `Food.txt` are
local surfaces and must not be committed.

Use `python -m mantle status` to inspect the construction. Birth requires the
separate, explicit `--approve-birth` gate. The optional Hermes adapter is inert
until it is deliberately installed and enabled through Hermes's plugin system.
