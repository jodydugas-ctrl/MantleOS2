# Donor Decision Log

Older implementations are evidence and donor material, not authority. Decisions
below explain why an idea entered or stayed out of the alpha bootstrap.

| Source concept | Decision | Reason |
| --- | --- | --- |
| Body-first operation without MIND | Keep | Required by the current contract and host-survival rule. |
| Explicit birth gate and first full Heartbeat | Keep and strengthen | Separates preparation, attempt, and successful birth. |
| Encrypted append-only VCW with hash chains | Adapt | Retain integrity and extension behavior; treat each physical file as an extension of one logical layer/Book. |
| Read-only repository census | Keep | Establishes evidence without executing or mutating candidate host code. |
| Git-native Daemon receipts and checkpoints | Adapt later | Useful evidence pattern, but Git history is not the organism's VCW. |
| Persona distillation prompt and examples | Adapt | Use as developmental evidence; the candidate cannot approve or birth itself. |
| Hermes project plugin hooks | Adapt | Correct edge mechanism, but activation must be explicit and user-facing settings belong in Hermes config. |
| MacroDroid/Android sensors and actions | Defer | Valuable ecology proof, outside the lean Hermes alpha surface. |
| PNG VCW representation | Defer as candidate | Demonstrated transport/storage phenotype; not required for canonical alpha memory. |
| SPORE Tomb candidate | Defer as candidate | Useful conformance seed, but migration and continuity law remain open. |
| “Zombie Body” API and lifecycle | Reject | Superseded by Default Body/Layer 0 = NEST and repeatedly confused implementers. |
| Brain organ or permanent LLM loop | Reject | The brain-stem phrase is metaphor; MIND is optional and Body-governed. |
| Autonomous host rewriting | Reject | Violates OTHER/SELF boundary, explicit authority, and host preservation. |
| Whole older MantleOS 2 tree | Reject wholesale import | Contains useful modules but also obsolete contracts, excess surface, and dependency/test drift. |
